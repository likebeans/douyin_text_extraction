# 抖音视频文本提取工具 - Web 界面

这是抖音视频文本提取工具的 Web 界面版本，提供了一个简单易用的图形界面。

## 🚀 快速开始

### 1. 安装依赖

```bash
# 在 douyin_practice_web 目录下
uv sync
```

### 2. 配置 API Key

首次使用前，需要配置 DashScope API Key：

**方法一：通过 Web 界面配置（推荐）**
1. 启动 Web 应用
2. 访问 `http://localhost:5000/config`
3. 填入你的 API Key 并保存

**方法二：创建 .env 文件**
```bash
# 复制示例配置
cp .env.example .env

# 编辑 .env 文件，填入你的 API Key
DASHSCOPE_API_KEY=sk-your-api-key-here
```

### 3. 启动 Web 应用

```bash
# 方式一：使用 run_web.py
uv run python run_web.py

# 方式二：直接运行 web_app.py
uv run python web_app.py
```

启动后，访问 `http://localhost:5000` 即可使用。

## 📖 使用说明

### 主页面

1. **输入抖音链接**：在输入框中粘贴抖音视频链接或分享口令
   - 支持短链接：`https://v.douyin.com/xxxxx/`
   - 支持完整链接：`https://www.douyin.com/video/xxxxx`
   - 支持分享文本（包含链接的完整文本）

2. **点击"开始提取"**：系统会自动解析链接、获取视频信息并进行语音识别

3. **查看结果**：
   - **视频信息**：显示标题、作者、时长、视频ID等元数据
   - **提取文本**：重点展示识别出的文本内容

### 配置页面

访问 `http://localhost:5000/config` 可以配置以下参数：

- **DashScope API Key**（必需）：阿里云 DashScope 的 API Key
- **最大视频时长**：超过此时长的视频将被拒绝处理（默认 600 秒）
- **ASR 模型**：选择语音识别模型（默认 paraformer-v2）
- **输出目录**：文本文件的保存目录（可选）

配置保存后会立即生效，无需重启服务。

## 🎨 功能特点

- ✅ **简单易用**：直观的 Web 界面，无需命令行知识
- ✅ **实时配置**：支持通过 Web 界面配置和修改参数
- ✅ **重点展示文本**：结果页面重点展示提取的文本内容

## 🔧 技术栈

- **后端**：Flask 3.0
- **前端**：原生 HTML/CSS/JavaScript
- **样式**：现代渐变设计，响应式布局

## 📝 注意事项

1. **API Key 安全**：配置页面会部分隐藏 API Key（只显示前 10 位）
2. **视频时长限制**：默认限制为 10 分钟，可在配置页面修改
3. **处理时间**：根据视频时长不同，处理时间约为视频时长的 1/3
4. **网络要求**：需要能够访问抖音和阿里云服务

## 🐛 故障排除

### 提示"配置错误"

- 检查是否已在配置页面设置了 `DASHSCOPE_API_KEY`
- 确认 API Key 是否有效且未过期

### 链接解析失败

- 检查链接格式是否正确
- 确认链接是否有效（在浏览器中打开试试）
- 检查网络连接是否正常

### 语音识别失败

- 检查 API Key 是否有足够的额度
- 确认视频时长是否超过限制
- 查看服务器日志获取详细错误信息
