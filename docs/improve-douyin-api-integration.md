# 抖音页面解析集成记录

本文件记录页面解析策略的背景。它不是当前接口规范或端到端测试报告；页面结构、链接可用性和网络行为可能变化。请以当前源码、离线测试和 [README](../README.md) 为准。

## 当前流程

共享提取流程按顺序解析输入链接、获取页面元数据，再调用 DashScope 或本地 Whisper。请求超时和重试次数由 `REQUEST_TIMEOUT` 与 `RETRY_TIMES` 配置。DashScope 直接转写失败时，可按配置尝试 OSS + FFmpeg 备用流程。

## 验证范围

默认测试模拟第三方依赖，不访问抖音、DashScope 或 OSS。当前项目没有公开端到端成功率、准确率、处理速度或费用基准。验证真实平台行为需要单独安排受控集成测试并使用专用凭据。
