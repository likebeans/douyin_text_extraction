## 📝 文档规范

### 文档命名

- 使用小写字母和连字符：`link-parser-fix.md`
- 描述性命名，清晰表达文档内容
- 日期格式：YYYY-MM-DD

### 文档结构

每个问题修复文档应包含：

1. **问题描述** - 清晰描述问题现象
2. **问题原因分析** - 深入分析问题根源
3. **解决方案** - 详细的修复方案
4. **技术细节** - 代码变更和实现细节
5. **测试验证** - 测试用例和验证结果
6. **经验总结** - 从问题中总结的经验
7. **后续改进** - 未来改进建议
