# 网络访问问题排查指南

## 问题：HTTP 502 错误，无法通过局域网 IP 访问

### 问题原因

你的系统有多个网络接口：
- `192.168.212.120` (WLAN) - **这是正确的局域网 IP**
- `198.18.0.1` (Meta) - 这是虚拟接口，不是实际局域网 IP

如果访问了 `198.18.0.1:5000`，会出现 502 错误，因为这不是用于局域网访问的接口。

### 解决方案

#### 1. 使用正确的 IP 地址

**正确的访问地址：**
```
http://192.168.212.120:5000
```

**错误的访问地址（不要使用）：**
```
http://198.18.0.1:5000  ❌
```

#### 2. 查找正确的 IP 地址

运行以下脚本查找正确的局域网 IP：

```powershell
.\scripts\get_local_ip.ps1
```

#### 3. 确保 Flask 监听所有接口

Flask 应用应该监听 `0.0.0.0`，而不是 `127.0.0.1`。

检查方法：
```powershell
netstat -ano | findstr :5000
```

应该显示：
```
TCP    0.0.0.0:5000           0.0.0.0:0              LISTENING
```

如果显示 `127.0.0.1:5000`，说明只监听本地，需要修改配置。

#### 4. 检查防火墙

确保防火墙已开放端口 5000：

```powershell
# 以管理员身份运行
.\scripts\open_firewall_port.ps1 5000
```

#### 5. 重启 Flask 应用

修改配置后，需要重启 Flask 应用：

```powershell
# 停止当前应用（Ctrl+C）
# 然后重新启动
.\run_web.ps1
```

启动后，查看输出的 IP 地址，应该显示：
```
🌐 局域网访问: http://192.168.212.120:5000
```

### 快速检查清单

- [ ] 使用正确的 IP 地址：`192.168.212.120:5000`
- [ ] Flask 监听 `0.0.0.0:5000`（不是 `127.0.0.1`）
- [ ] 防火墙已开放端口 5000
- [ ] Flask 应用正在运行
- [ ] 浏览器清除缓存后重试

### 测试连接

```powershell
# 测试本地连接
curl http://localhost:5000

# 测试局域网连接
curl http://192.168.212.120:5000
```

### 如果仍然无法访问

1. **检查是否有其他服务占用端口**
   ```powershell
   netstat -ano | findstr :5000
   ```

2. **检查 Windows 防火墙**
   ```powershell
   Get-NetFirewallRule | Where-Object { $_.DisplayName -like "*5000*" }
   ```

3. **尝试使用其他端口**
   ```powershell
   $env:FLASK_PORT = "8080"
   .\run_web.ps1 8080
   ```

4. **检查网络连接**
   - 确保设备在同一局域网
   - 检查路由器设置
   - 尝试 ping 测试
